# Situated Embedding Models for Context-Aware Dense Retrieval

## 一話摘要
本文不是把 chunks 切得更大，而是讓 **short chunk representation conditioned on broader document context**，並提出專門訓練的 situated embedding model。

## Boundary
- **D04 primary**：改變 corpus-side representation。
- **D02 secondary**：解決 chunk 脫離全文後的 contextualization 問題。
- 不因用於 retrieval 就把它設成 D05 primary。
