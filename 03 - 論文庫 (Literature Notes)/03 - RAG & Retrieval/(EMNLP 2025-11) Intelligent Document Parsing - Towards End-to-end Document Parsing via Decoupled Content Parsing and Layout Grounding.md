# Intelligent Document Parsing

## 一話摘要
IDP 將 pixel/scanned documents 的 parsing 從分離式 layout/OCR pipeline 改成 MLLM-based end-to-end parsing，並以 decoupled content parsing + layout grounding 降低語意碎裂與 error propagation。
