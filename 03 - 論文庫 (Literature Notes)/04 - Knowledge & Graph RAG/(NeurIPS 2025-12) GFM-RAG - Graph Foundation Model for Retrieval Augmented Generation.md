# GFM-RAG: Graph Foundation Model for Retrieval Augmented Generation

## 一話摘要
以 graph neural network 建立可跨 unseen datasets 泛化的 graph foundation **retriever**，在 graph-index 上做 query-conditioned reasoning，學習 query–knowledge relationships。

- **D04 secondary**：方法依賴 graph index。
