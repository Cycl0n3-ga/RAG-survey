# RioRAG: Reinforced Informativeness Optimization for Long-Form Retrieval-Augmented Generation

## 一話摘要
把 long-form RAG 的 **informativeness** 轉成可外部驗證的 RL reward，使用 nugget-centric verification 與 cross-source checks，讓 long-form answer optimization 同時考慮 factual recall 與 faithfulness。
