# RARR: Researching and Revising What Language Models Say, Using Language Models

## 一話摘要
RARR 為既有 LM output 自動搜尋 supporting attribution，並 **post-edit unsupported content**，在保留原始文字的同時提高可歸因性。

## Taxonomy
- **D09 primary**：核心是 attribution + unsupported-claim revision。
- **D05 secondary**：方法會為待查核 claims 發出 web search。
- 它是 generation/post-generation repair，而不是單純的 evaluation paper。
