# 6. 去重與 Metadata Gate

每篇候選在建立 dedicated note 前，必須依序完成：

- [ ] 以 DOI 查重。
- [ ] 以 arXiv ID 查重。
- [ ] 以 ACL Anthology / OpenReview / PMLR / NeurIPS / AAAI / ACM 正式識別碼查重。
- [ ] 搜尋完整 title，確認沒有舊檔名或不同資料夾版本。
- [ ] 區分 `year`（初次公開 / preprint）與 `publication_year`（正式出版）。
- [ ] 若 arXiv 後來正式發表，只保留一份主 Literature Note；frontmatter 同時保留 arXiv 與正式 venue。
- [ ] `artifact_type` 正確：`method_paper` / `benchmark_paper` / `dataset` / `evaluation_framework` / `survey`。
- [ ] 若只有 abstract，`verification_status: abstract_only`；不可填寫假裝來自全文的 Table/Figure 數字。
- [ ] 若正式出版狀態不確定，`publication_year: null`、`venue: arXiv` 或依實際來源填寫，並標 `pending_verification`。
- [ ] 不把 benchmark 名稱與方法縮寫混為一談，例如 Corrective RAG vs Comprehensive RAG Benchmark（CRAG）。
- [ ] 不把同一 paper 由不同 Domain 重複建立多份 note；使用多個 `domains` Wikilinks。

# 7. 每篇新 Note 的 Definition of Done

一篇論文只有在以下項目完成後，才能從 backlog 勾成完成：

- [ ] metadata 由 primary source / official index 核對。
- [ ] PDF 可取得；若不可取得，清楚標示 `abstract_only`。
- [ ] YAML frontmatter 符合 `AGENTS.md`。
- [ ] TL;DR、Problem、Methodology、Empirical Results、Trade-offs、Implications、Sources 七節齊全。
- [ ] 所有關鍵實驗數字標 Table/Figure/Page 與條件。
- [ ] 至少連回 1 個 Research Domain。
- [ ] 若為 benchmark/dataset，說明 gold unit、split、metric、modality、license/access、可測與不可測內容。
- [ ] 若為 method paper，列出至少 1 個可比較 baseline 與失效條件。
- [ ] 更新 `03 - 論文庫 (Literature Notes)/README.md`。
- [ ] 檢查 Wikilinks 與 Papers 路徑。
- [ ] 確認沒有把 project hypothesis 寫成 paper finding。

# 8. 停止條件

不要以「100 篇」作為唯一目標。某個 Domain 可暫停補文獻，需同時滿足：

1. 至少有 1 篇 survey / review / benchmark overview 支撐該研究線存在；
2. 至少有 3–5 篇 primary method papers 覆蓋主要方法族；
3. 至少有 1–2 個可實際使用的 benchmark/dataset；
4. 主要 baseline、failure mode、metric、gold unit 都有來源；
5. 近兩年代表性工作沒有明顯空洞；
6. 新增下一篇論文不再改變 taxonomy、baseline matrix、benchmark choice 或 research gap 判斷。

若未滿足以上條件，繼續補；若已滿足，優先把時間投入 **全文核對、實驗條件、錯誤修正與跨 Domain 統整**，而不是無限增加 paper count。
