## Metadata Standard

每篇 paper note 使用：

```yaml
taxonomy_version: "v2"
taxonomy_home: "D05"
primary_domain: "D05"
secondary_domains:
  - "D04"
paradigm_tags:
  - "graph_rag"
adjacent_interfaces: []
```

Adjacent-only paper 可使用：

```yaml
taxonomy_home: "A01"
primary_domain: null
secondary_domains: []
paradigm_tags:
  - "long_context"
adjacent_interfaces:
  - "A01"
```

不再維護額外的 `domains` 欄位或其他平行 Domain 編號。
